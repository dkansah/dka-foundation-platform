# DKA FOUNDATION Platform

> A comprehensive NGO platform combining legal documentation, web application, campaign management, interactive pitch deck, and donor journey mapping.

## 🎯 Overview

DKA FOUNDATION Platform is a complete solution for managing a modern NGO's digital presence, fundraising campaigns, and stakeholder engagement.

## 🚀 Features

### 1. **Document Generator**
- UK Charity Commission-ready Constitution
- Trustee Declaration Forms
- Financial Plans
- Mission, Vision & Values Statements
- Charitable Objects Statements

### 2. **Web Application**
- Interactive "About Us" page
- Cinematic storytelling interface
- Donation platform integration
- Volunteer/Partnership sign-up
- Impact tracking dashboard

### 3. **Campaign Management System**
- 6-week rollout calendar
- Social media scheduler
- Email campaign templates
- Multi-channel coordination
- Analytics tracking

### 4. **Interactive Pitch Deck**
- Cinematic slide presentations
- Auto-play with narration
- Video embedding
- Donor appeal integration
- Export to PDF/video

### 5. **Donor Journey Mapper**
- 5 donor personas (Innovator, Compassionate Giver, Community Builder, Environmental Guardian, Justice Advocate)
- Channel-specific messaging
- Funnel visualization
- Persona campaign matrix
- Advocacy loop tracking

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla + Chart.js)
- **Backend**: Node.js (optional for advanced features)
- **Data**: JSON-based storage
- **Deployment**: GitHub Pages / Vercel

## 📖 Getting Started

1. Clone the repository
2. Navigate to the relevant feature branch for each component
3. Follow component-specific README files in each directory
4. Configure `config.json` with foundation details
5. Deploy to web server or GitHub Pages

## 🎨 Features by Branch

- `feature/document-generator` - Legal documents & templates
- `feature/web-application` - Website and landing pages
- `feature/campaign-manager` - Social media & email campaigns
- `feature/pitch-deck` - Investor presentations
