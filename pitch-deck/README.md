# Interactive Pitch Deck

Cinematic presentation for DKA FOUNDATION featuring 8 slides with smooth transitions.

## 📁 Slides

1. **Opening Frame** - Mission tagline & branding
2. **Our Story** - Foundation origin & purpose
3. **Mission & Vision** - Dual statement view
4. **Our Values** - 7-value visual grid
5. **What We Do** - 6 focus areas
6. **Our Impact** - Key metrics & achievements
7. **Call to Action** - Donate, Partner, Volunteer
8. **Closing** - Logo & contact info

## 🚀 Features

- Smooth fade transitions
- Keyboard navigation (arrow keys)
- Progress bar tracking
- Responsive mobile design
- Auto-play capability
- Professional cinematic layout

## 📱 Navigation

**Desktop:**
- Arrow keys to move between slides
- Click Previous/Next buttons

**Mobile:**
- Swipe left/right (can be added)
- Touch Previous/Next buttons

## 🎨 Customization

### Colors
- Primary Blue: `#003366`
- Gold Accent: `#FFD700`
- Green: `#00A86B`

### Add Video Backgrounds
Replace slide backgrounds with video:
```css
.slide-background {
    background: url('video.mp4') cover;
    background-attachment: fixed;
}
```

### Add Narration
Add audio to slides:
```html
<audio id="narration-1" src="slide1-narration.mp3"></audio>
```

## 📊 Integration Points

- Connect CTA buttons to donation platform
- Add video embeds to story slides
- Integrate presenter notes (speaker view)
- Add transitions/animations
- Export to PDF or video

## 🔒 Production Use

1. Open `index.html` in browser
2. Full-screen mode (F11)
3. Present to investors/donors
4. Use keyboard or buttons to navigate
5. Timer view available (can be added)
